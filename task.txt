ЗАДАНИЕ БЕЗ ДОСТУПА К СИСТЕМАМ
Тестовое задание для ИТ-специалиста
Задача: развернуть локальный тестовый сервис и настроить получение данных из него. Доступ к системам предприятия не требуется.
Время выполнения: 2–3 часа. Можно пользоваться документацией и готовыми инструментами.
Исходные данные
Используйте три условные записи:
ID сотрудника	ФИО	Участок	Должность
001	Иванов Иван Иванович	Прессование	Прессовщик
002	Петров Пётр Петрович	Упаковка	Упаковщик
003	Сидоров Сергей Сергеевич	Мехобработка	Оператор
Что необходимо сделать
Установить и запустить локальный сервис, который выдаёт эти данные через HTTP в формате JSON. Можно использовать готовое ПО — разработка собственного приложения не обязательна.
Настроить отдельный доступ для чтения с авторизацией по логину и паролю либо токену.
Подключиться к сервису через другой инструмент: браузер, Postman, curl или аналог. Получить список сотрудников.
Проверить ограничения доступа:
с правильными учётными данными чтение работает;
без авторизации или с неверными данными доступ запрещён;
попытка изменить данные отклоняется, исходные записи остаются неизменными.
Воспроизвести и устранить две неисправности:
неверный адрес или порт подключения;
неверные учётные данные.
Составить короткую инструкцию: как запустить сервис, подключиться к нему и проверить его работу.
Что предоставить
Файлы настроек или архив тестового стенда, необходимые для повторного запуска.
Команды или запросы для проверки чтения и ограничений доступа.
Краткий отчёт: что настроено, какие ошибки возникли, как определена и устранена их причина.
Скриншоты результатов проверок.
Критерий выполнения: другой специалист может по инструкции запустить стенд, получить данные с разрешённым доступом и убедиться, что неавторизованный доступ и изменение данных запрещены.
