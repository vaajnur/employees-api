## Воспроизведение и устранение неисправностей

### 1. Неверный адрес или порт подключения

**Симптом:** `curl: (7) Failed to connect` / Connection refused.

**Воспроизведение:**

```bash
# сервис слушает 8080, клиент обращается на другой порт
curl -sS http://127.0.0.1:9999/employees
```

**Диагностика:**

```bash
# проверить, слушает ли процесс порт
ss -lntp | grep 8080
# или
curl -sS http://127.0.0.1:8080/health
```

**Устранение:** запускать сервис на нужном порту (`PORT=8080 ./start.sh`) и в клиенте указывать тот же хост/порт. При деплое на сервер — открыть порт в firewall и использовать внешний IP/домен.

### 2. Неверные учётные данные

**Симптом:** HTTP `401 Unauthorized`, тело `{"error":"unauthorized",...}`.

**Воспроизведение:**

```bash
curl -sS -i -u 'reader:wrong-password' http://127.0.0.1:8080/employees
```

**Диагностика:** сверить логин/пароль или токен с `config.php` / разделом «Учётные данные» в `ИНСТРУКЦИЯ.md`.

**Устранение:** использовать верные данные:

```bash
curl -sS -u 'reader:ReadOnly2026!' http://127.0.0.1:8080/employees
# или
curl -sS -H 'Authorization: Bearer emp-read-token-9f3a2c' http://127.0.0.1:8080/employees
```
