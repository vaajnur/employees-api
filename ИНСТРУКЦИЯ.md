# Тестовый стенд: Employees API (PHP)

Локальный HTTP-сервис выдаёт список сотрудников в JSON. Доступ только на чтение, с авторизацией.

## Требования

- PHP 8.0+ (`php-cli`)

## Запуск

```bash
cd /path/to/aluminum_garden
chmod +x start.sh
./start.sh
```

По умолчанию: `http://0.0.0.0:8080`

Другой порт:

```bash
PORT=9090 ./start.sh
```

Или вручную:

```bash
php -S 0.0.0.0:8080 -t public router.php
```

## Учётные данные (только чтение)

| Способ | Значение |
|--------|----------|
| Basic Auth | логин `reader`, пароль `ReadOnly2026!` |
| Bearer-токен | `emp-read-token-9f3a2c` |

## Эндпоинты

| Метод | URL | Auth | Описание |
|-------|-----|------|----------|
| GET | `/health` | нет | Проверка, что сервис запущен |
| GET | `/employees` | да | Список сотрудников |
| POST/PUT/PATCH/DELETE | `/employees` | — | Всегда 405 (запись запрещена) |

## Проверка работы

### 1. Сервис жив (без авторизации)

```bash
curl -sS http://127.0.0.1:8080/health
```

### 2. Чтение с правильным логином/паролем

```bash
curl -sS -u 'reader:ReadOnly2026!' http://127.0.0.1:8080/employees
```

### 3. Чтение с токеном

```bash
curl -sS -H 'Authorization: Bearer emp-read-token-9f3a2c' http://127.0.0.1:8080/employees
```

### 4. Без авторизации — отказ (401)

```bash
curl -sS -i http://127.0.0.1:8080/employees
```

### 5. Неверные учётные данные — отказ (401)

```bash
curl -sS -i -u 'reader:wrong' http://127.0.0.1:8080/employees
```

### 6. Попытка изменить данные — отказ (405), записи не меняются

```bash
curl -sS -i -u 'reader:ReadOnly2026!' -X POST \
  -H 'Content-Type: application/json' \
  -d '{"id":"004"}' \
  http://127.0.0.1:8080/employees

# Повторное чтение — те же 3 сотрудника
curl -sS -u 'reader:ReadOnly2026!' http://127.0.0.1:8080/employees
```

## Развёртывание на сервере (nginx + php-fpm)

Документы корневой директории сайта указывают на каталог `public/`. Пример фрагмента nginx:

```nginx
server {
    listen 80;
    server_name _;
    root /var/www/employees-api/public;
    index index.php;

    location / {
        try_files $uri /index.php?$query_string;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_param HTTP_AUTHORIZATION $http_authorization;
        fastcgi_pass unix:/run/php/php-fpm.sock;
    }
}
```

После деплоя замените хост в командах `curl` на адрес сервера.
